# Агрегаты

## Бронь (Booking)
**Корень**: `Booking` · **Контекст**: Бронирование
### Состав
| Элемент | Вид | Почему так |
|---|---|---|
| `Booking` | Сущность, корень | Имеет тождество |
| `TimeRange` | Значение | Два интервала 9-12 — один и тот же |
| `BookingStatus` | Значение (enum) | active / cancelled / withdrawn / completed |
| `Participant` | Сущность внутри | Тождество только внутри брони |

### Инварианты
| № | Инвариант |
|---|---|
| И-1 | Интервал положителен: `ends_at > starts_at` |
| И-2 | Длительность не больше 8 часов |
| И-3 | Число участников не больше вместимости |
| И-4 | У снятой админом брони есть причина |

### Что инвариантом НЕ является
| Правило | Почему | Где проверяется |
|---|---|---|
| Комната не занята | Нужны другие брони | В сервисе (сценарий) |
| Комната в рабочее время | Нужен агрегат Комната | В сервисе |

### События
`BookingCreated`, `BookingCancelled`, `BookingWithdrawn`, `VisitorArrived`.

## Комната (Room)
**Корень**: `Room`
### Состав
`Room`, `RoomCode` (номер), `Capacity` (вместимость), `Equipment` (список оборудования).
### Инварианты
- Номер уникален.
- Вместимость > 0.
