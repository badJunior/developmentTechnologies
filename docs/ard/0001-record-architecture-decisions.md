# 1. Мы ведём записи об архитектурных решениях
- **Статус**: принято
- **Дата**: 2026-11-12

## Контекст
Решения принимаются в разговоре и забываются. Через месяц причину не вспомнить.

## Решение
Ведём записи в `docs/adr/` по формату MADR. Не правятся, а заменяются новыми.

## Последствия
+ Причина решений доступна.
- Требует времени на написание.
